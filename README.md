This is an e-commerce storefront and admin management system for an artisanal coffee shop built with Next.js, Supabase, and Tailwind CSS.

### Getting Started
Clone the repository and install dependencies:

```bash
git clone [https://github.com/charissejamien/up-and-grinding.git](https://github.com/charissejamien/up-and-grinding.git)
cd up-and-grinding
npm install
```

### Run Development Server

```bash
npm run dev
```
Open http://localhost:3000 in your browser.
